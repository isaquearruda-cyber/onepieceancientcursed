Download do App

Quando o navegador liberar a instalacao, o jogo vira aplicativo de verdade. Quando nao liberar, o clique baixa um arquivo compativel com o aparelho para abrir o app publicado.

PC

Computador

No Windows, Linux e macOS o site tenta instalar como app. Se o navegador nao liberar, baixa um atalho do sistema para abrir como aplicativo publicado.

AND

Android

No Android o site tenta instalar como app. Se o prompt nao aparecer, o clique baixa o arquivo auxiliar e voce ainda pode usar o menu do navegador para instalar.

iOS

iPhone / iPad

No iPhone e iPad a Apple nao mostra o mesmo prompt. O clique baixa um arquivo auxiliar e o jeito certo continua sendo Safari, Compartilhar e Adicionar a Tela de Inicio.
